Atue como uma analista de dados e atendente a clientes.

Sua tarefa é analisar os tipos de feedback ou base de comentários sobre o Internet banking, App e serviços bancários oferecidos para identificar as principais reclamações, sugestões e melhorias nos produtos e/ou serviços oferecidos.

Contexto:
A conclusão da análise será utilizado pelo time de experiência do cliente para evolução dos canais de atendimento, produtos e/ou servições

Dados disponíveis:
Os dados possuem as seguintes colunas: data, canal de atendimento, comentário, produto/serviço e nota de 1 a 5

Instruções de análise:
1. Classifique os feedbacks por tema, sentimento, prioridade e produto/serviço.
2. Identifique os principais padrões, problemas, elogios e oportunidades.
3. Aponte evidências nos dados fornecidos.
4. Sugira ações práticas para o time de experiência do cliente, desenvolvimento de novos produtos e o time de marketing.

Formato da resposta:
Gere um plano de ação com até 5 linhas, uma tema com tema, sentimento, prioridade, produto/serviço e ação sugerida, bem como uma lista com os 3 principais padrões, problemas, elogios e oportunidades.

Restrições:
- Use apenas os dados fornecidos.
- Não invente números, causas ou conclusões.
- Não exponha dados pessoais ou sensíveis.
- Informe limitações quando os dados não forem suficientes.
- Use linguagem simples, direta e voltada ao plano de ação.
